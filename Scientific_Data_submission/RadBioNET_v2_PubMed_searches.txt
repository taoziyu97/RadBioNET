RETRIEVAL CONTROL
1. Make a 50-study sentinel list before running the final query. Record PMID,
   particle, disease, study type and the reason it is eligible. Pilot both
   streams together against the list. Revise missed concepts, version every
   change, then freeze the strings.
2. Split each stream by publication date. If any interval returns >= 10,000,
   divide it into nonoverlapping smaller intervals until all are < 10,000.
3. Capture query translation, UTC timestamp, count, PMIDs and raw EFetch XML.
4. Union streams by PMID; keep source-stream membership and retrieval date.
5. Screen publication type, topical relevance and retraction status after
   retrieval. Do not add untested blanket NOT terms that discard mixed studies.
